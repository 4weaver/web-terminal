# Vendored Nerd Fonts

Regular **Nerd Font Mono** cuts only, converted to `woff2`. The page loads
whichever face `WT_FONT` selects (`GET /api/config`), not all three.

| `WT_FONT` | File | Upstream |
|---|---|---|
| `lilex` | `LilexNerdFontMono-Regular.woff2` | [Lilex](https://github.com/mishamyrt/Lilex) via [nerd-fonts](https://github.com/ryanoasis/nerd-fonts) |
| `jetbrains-mono` | `JetBrainsMonoNerdFontMono-Regular.woff2` | JetBrains Mono NL via nerd-fonts |
| `iosevka` | `IosevkaTermNerdFontMono-Regular.woff2` | Iosevka Term via nerd-fonts |
